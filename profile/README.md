# Ai Instant Lab

**Instant Insight. Intelligent Action.**

Ai Instant 是一个讲 AI 的自媒体，抖音、小红书、公众号同名。这里放它的开源部分：做内容用的工作流、整理好的资料，还有网站本身的代码。

- **网站** [aiinstantlab.com](https://aiinstantlab.com)：每天一课 AI 原理，再算一笔产品账；每周一、三、五一期 AI 产品趋势。全部免费公开。
- **工具** [Frontmost](https://frontmost.co)：AI 工具与灵感书签。
- **社区** [讨论区](https://github.com/aiinstantlab/community/discussions)：问问题、提选题、纠错。
